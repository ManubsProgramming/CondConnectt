# 🏢 CondConnect

🚧 **Projeto em desenvolvimento**

O **CondConnect** é um sistema desenvolvido como parte de um **Trabalho de Conclusão de Curso (TCC)**, com o objetivo de facilitar a comunicação entre a portaria e os moradores de um condomínio.

A aplicação foi planejada como uma solução tecnológica para centralizar e organizar a comunicação condominial, aplicando conceitos de desenvolvimento backend e arquitetura de sistemas.

## 🎓 Projeto acadêmico

Este projeto foi desenvolvido no contexto de um **Trabalho de Conclusão de Curso (TCC)**, com foco na criação de uma solução tecnológica para melhorar a comunicação em ambientes condominiais.

## 🚀 Objetivo do projeto

Desenvolver um sistema que auxilie na comunicação entre moradores e a administração/portaria do condomínio, tornando o fluxo de informações mais organizado e eficiente.

## 🛠️ Tecnologias utilizadas

* Java
* Spring Boot
* Spring Web
* Spring Data JPA
* Spring Security
* JWT
* PostgreSQL
* Lombok
* Maven

## 🧱 Estrutura do projeto

O projeto foi organizado seguindo uma arquitetura baseada na separação de responsabilidades:

* **Controller** — Gerenciamento das requisições da API;
* **DTO** — Transferência de dados entre as camadas;
* **Entity** — Representação das entidades do sistema;
* **Repository** — Acesso e comunicação com o banco de dados;
* **Service** — Implementação das regras de negócio;
* **Security** — Configurações relacionadas à segurança e autenticação.

## 🔐 Segurança

O projeto utiliza **Spring Security** e possui estrutura preparada para autenticação baseada em **JWT (JSON Web Token)**.

## 📌 Status do projeto

O projeto encontra-se em desenvolvimento e algumas funcionalidades ainda estão sendo implementadas.
